# RFCs

Architectural proposals for Napsed. Copy `0000-template.md`. Implementation PRs come after the RFC is accepted.

In-scope for an RFC:

- New `executionTier` or runtime
- Breaking `SpecManifest` fields
- Defense-gate or proof-hash semantics
- Moving code across `specs/` / `runner-wasm/` / `ui/` / a future `cloud/` API
